## 现在在做什么

- 🧭 **LetterMate**：把多来源信息检索、去重、事实支持和中文摘要收进一个 Feed。
- 🎬 **DanmuAI**：让桌面画面拥有会观察、会吐槽、会说话的 AI 弹幕。
- 🧱 关注从 **模型调用 → 业务闭环 → 用户体验** 的完整链路，而不只是把 API 接上。
- ✍️ 喜欢写清楚边界、状态和失败路径，让项目能被长期维护。
