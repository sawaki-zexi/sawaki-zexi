# 泽熙 / Zexi

我是一名独立开发者，目前专注于 **AI Agent 领域**。

我喜欢把模型能力放进具体的工作流里，让 Agent 真正理解任务、调用工具并完成事情。

## 项目

- [LetterMate](https://github.com/sawaki-zexi/LetterMate) — 面向个人的信息发现工作台。把关键词追踪、趋势发现、多来源检索和中文摘要放进一个 Feed。
- [DanmuAI](https://github.com/sawaki-zexi/danmuai) — Windows 桌面 AI 弹幕助手。识别屏幕内容，生成弹幕，并用透明浮层和语音回应。
